# Sample NOAA ENC cells

These official NOAA S-57 ENC packages were downloaded on 2026-11-26 and unpacked here. The application recursively indexes the `.000` base cells at startup; each cell's update files are kept beside it.

- `US5BOSCC`: Boston Inner Harbor, Charles River and Neponset River entrance to Old Harbor. [NOAA ZIP](https://www.charts.noaa.gov/ENCs/US5BOSCC.zip)
- `US5BOSCD`: President Roads to Boston Inner Harbor. [NOAA ZIP](https://www.charts.noaa.gov/ENCs/US5BOSCD.zip)
- `US5BOSDC`: Boston Inner Harbor to Mystic River and Chelsea River. [NOAA ZIP](https://www.charts.noaa.gov/ENCs/US5BOSDC.zip)

Source: [NOAA ENC download page](https://charts.noaa.gov/ENCs/ENCs.shtml). These samples are for software testing and visualization, not navigation. Consult NOAA's current products and terms before operational use.
